# 武器故事精读：旧蒙德贵族系列——宗室长剑与宗室长弓

> 按 STANDARD v1.0 重建。底稿：archives_v1/weapon_旧蒙德贵族系列.md（v1，引文已验证，作者已核实迁入）。语料：武器故事 宗室长剑（11404，4星单手剑，Weapon11404）/ 宗室长弓（15404，4星弓，Weapon15404）；所属国别蒙德（旧贵族时代），世界观价值评级 S。
> 器物文本即一手来源，断言置信一律「明文」；旁白＋立誓/流放者直接引语，叙事流按【旁白】/【说话人】标注。

## 一、叙事流摘要

### 宗室长剑（11404）
【旁白】「曾支配蒙德的旧日贵族所使用的长剑，做工用料极其讲究」「在他们的时代过去无数世代后，仍然锋利如当初」。剑术曾是贵族必修：「习剑是为了培养智慧与优雅」，但「最终他们忘却了智慧与优雅，剑术沦为形式」。
【旁白】核心史料为两千六百年前的立誓：「蒙德大地上最古老的血脉们，在新风神降生重塑天地后，立下庄重的誓言」。
【立誓贵族】「永护蒙德，永护蒙德青绿的平原、山岭与丘陵与森林，愿它永葆苍翠」「永护蒙德，不再受暴君般的风雪，风雪般的暴君所困，愿它永远自由」。
【旁白】「即便立誓的铭碑被毁」「誓言的灵魂仍然随着千风，如恋人般轻抚着蒙德，如父亲般保卫着蒙德」。

### 宗室长弓（15404）
【旁白】旧贵族狩猎用长弓：「在自然天地彰显力量，将猎获分给属下的人民，广施德望」，但「最终他们忘却了德望，也失去了支配的力量」。
【旁白】「起义后，长久统治蒙德的劳伦斯一族被推翻」「而是将一族余党流放至蒙德境外，永不复归」。
【流放者后代】「过了很多年，我才明白，背叛了、变了的是我们劳伦斯一族。蒙德本就应是那样的」。
【旁白】温妮莎的历史定位：「温妮莎不过是推倒腐朽大厦的最后一双手」「无论是受人暗地里称颂的暗巷义贼，或是能看见死亡的少女，还是意图行刺的剑乐团，蒙德人的血脉中传承着反抗的灵魂」。

## 三、时间锚

- 「两千六百年前」新风神（巴巴托斯）降生、重塑天地、古老血脉立誓——蒙德纪年上罕见的绝对年代锚点｜11404｜明文。
- 劳伦斯一族从「永护蒙德」的誓约守护者堕落为「暴君般」的统治者 → 起义被推翻 → 余党流放境外、永不复归｜15404｜明文。
- 温妮莎革命前夜：暗巷义贼、能看见死亡的少女、意图行刺的剑乐团——「推倒腐朽大厦」前的抗争者群像｜15404｜明文。

## 四、人物与关系变化

- 旧日贵族：曾支配蒙德 → 习剑本为智慧与优雅、狩猎本为广施德望 → 忘却智慧优雅与德望、剑术沦为形式、失去支配力量 → 被推翻流放。
- 最古老的血脉们：新风神降生后立「永护蒙德」庄重誓言；誓言虽被后世背弃，其灵魂仍随千风保卫蒙德。
- 劳伦斯一族：长久统治蒙德、自誓约守护者堕落为暴君；流放者后代晚年自认「背叛、改变的是我们」。
- 温妮莎：「推倒腐朽大厦的最后一双手」，此前已有义贼、预知少女、剑乐团相继抗争。

## 五、隐喻与代指

- 「暴君般的风雪，风雪般的暴君」：文内自铸对偶，自然之灾与僭主之政互喻。
- 「推倒腐朽大厦」：温妮莎革命之于旧贵族统治的比喻。
- 「能看见死亡的少女」：明写的抗争者别称（与具体角色的对应文本未点名，见第六节）。
