# 实体档案：努昂诺塔

> 按 STANDARD v1.0 重建。底稿：archives_v1/ent_26_努昂诺塔.md（实体档案批次F）；引文均逐字摘录自 v1 底稿所标出处。类型：器灵（月灵；由月神以自身灵魂碎片造出的生灵）。

## 一、叙事流摘要

【旁白】别称：努昂诺塔（arch_1600 talk 600023，菈乌玛命名）；月灵（类别）；「神秘的帮手」（arch_1607 talk 602320，众人对她的称呼，后揭示其真身）；哥伦比娅的「灵魂碎片」（Book1157 桑多涅术式记录）；「锚点」（arch_1608 talk 601522，尼可语，措辞为推测）。

【旁白】状态：明文存在。现状：在哥伦比娅回归后消失——派蒙「努昂诺塔也在哥伦比娅回来之后就不见了，我记得她解释说，那是她灵魂的一部分…」（arch_1608 talk 601701）。

【菈乌玛（arch_1600 talk 600029）】月灵源流：「传说库塔尔诞生之后，其身边立刻诞生了许多月灵。它们将月光编织成纱绢，为库塔尔披上了衣裳。」

【菈乌玛（arch_1600 talk 600023）】指认与赐福说：「神明的赐福有时会在很久之后，才不经意间变为努昂诺塔。二位或许是恰好见证了那一时刻吧。」

【哥伦比娅（arch_1607 talk 602326）】造物自述：「（是我让努昂诺塔诞生的，以我自身的一部分「灵魂」作为代价。）」；并指出因努昂诺塔诞生于某一时间点之后，「月亮倒影」在该时点之前不存在通往「过去」的门。

【尼可（arch_1608 talk 601522）】定位推测：「我想，努昂诺塔或许就是哥伦比娅小姐留下的「锚点」。作为一种未来的定位。」

【奈芙尔（arch_1608 talk 601524）】回看过去之说：「如果…这是哥伦比娅的一部分。而她知道我能够透过努昂诺塔看到过去发生的事呢…」

【Book1157（桑多涅术式记录）】术式枢纽：以努昂诺塔连接世界的「变数」（即「降临者」），将哥伦比娅的完整灵魂由「月亮倒影」空间反向寻回；旅行者的存活是术式成功的必要条件。

【旁白】经历：6.x 主线初旅行者救下被困的小动物，经菈乌玛指认为努昂诺塔，此后跟随旅行者左右（arch_1600）；祈月之夜被派蒙点为「特殊月灵」参与那夏镇的「月灵对对碰」游戏（arch_1606 talk 602734）；1607 哥伦比娅在月亮倒影中三次抵达「过去」，每次都现于旅行者身边，遂被众人视作「神秘的帮手」——后揭示其实为哥伦比娅自身布局（arch_1607 talk 602320）；1608 哥伦比娅回归提瓦特后，努昂诺塔随之消失（arch_1608 talk 601701）。
