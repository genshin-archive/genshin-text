## 一、叙事流摘要

**角色详细（见习水手的假象）**【摘要：初见者大多以为他不过是「南十字」船队的见习水手——个性平和、闲时酷爱吟诗、与人谈话总是一副悠然模样，「谁能看出他是受到稻妻幕府通缉的危险人物呢？」就连擅于识人的船长北斗，在决定收留前也没能看出这个平和的少年「出刀竟能如此利落，简直是身经百战之辈」。旁白留问：「不知是风雨磨平了少年人的棱角，还是本性内敛的他藏起了自己的锋芒。」】

**故事1（重佐的一句抱怨换来自报家门）**【摘要：璃月武装船队「南十字」经年航行于海波之上，旗舰「死兆星」号上就有一名出身别国的水手——他是在船队停泊于稻妻口岸离岛时被接上船的。船长北斗与这位年轻人是朋友，他来时北斗告诉手下：「这位兄弟要在船上停留一段时日，大家多关照关照他。」船员们相信北斗的眼光，也欣赏这个稻妻人「一身好武艺又有预判天气的本事」，哪怕他不愿透露私事仍同意留他在船上。但大家不会就此罢休，总找借口旁敲侧击：「听说稻妻出产的刀剑非常了不起，而且越是大人物越是会用好刀，你的刀怎么样？厉不厉害？」回应只有沉默。尝试多次未果，直到数天后大副重佐随口一句抱怨——「喂稻妻来的，你都没个名字，叫兄弟们怎么称呼你啊…」——水手抬起布满粗茧的手擦了擦汗：「我姓枫原，名万叶，原本是一名浪人武士。承蒙收留，大家请直接叫我万叶吧。」】

**故事2（枫原家末代子弟与自然的语言）**【摘要：万叶本非庶民，而是昔年稻妻贵胄——枫原家的末代子弟。「在豪门林立的稻妻城中，枫原一姓也曾叱咤风云。然而时运无常，当家业传至万叶手中时，枫原家已经是颓势如山倒了。」当时的少爷颇为无奈，可真到宅屋抵债、家仆散去的那一刻，他反倒松了口气：「以此为契机，做个浪迹天涯的自在人也不错。」漫游山林一直是他的心愿，自幼年便懂得欣赏自然的美与真；对他而言自然从不是静默的，「它一直在用独特的语言诉说心情」——「风声忽而止息，万物静默，那是天空垂泪前的平静。清泉忽而跃起，即是大地震怒的征兆。」这是自然赠予他的独特诗性，「万叶生来就不是汲汲于荣华之人」。家族重担不再，便轻装上路：「仿佛庭院中垂下一片落叶，随风散入天涯，万叶开始了他的旅程。」】

**故事3（狸妖的草庵：有房屋处风声会轻些）**【摘要：旅人在外总要有些傍身功夫，「听风观云的本事，便是万叶的底牌」。离开稻妻城后四处游历，天地山海成了最亲近的家园。初夏多雨、山路泥泞，夜降时他在路尽头看见一座草庵；同行结识的行商欢呼「万叶快看！晚上有地方住了！」万叶却不作声，侧耳倾听了许久才道：若要问我的意见…恐怕还是不去为好。行商不愿淋雨，当即丢下他一人去了草庵——有一位相貌美丽的妇人出来迎接，端来香茶、美味饭食与被褥；食物太过美味，行商吃着吃着便困了，倒头就睡。次日凌晨醒来，头上的房顶不知哪儿去了，阳光刺目，视野内只有正笑着俯视他的万叶；行商未等开口就吐出大把嚼过的树叶与泥巴，身下「哪有什么被褥，只是脏兮兮的泥地而已」。万叶点破：「有房屋的地方，风声会比别处轻些。可这山上风声照常，面前却有一处突如其来的草庵。依我看，你多半是被狸妖捉弄了吧？哎呀…出门行走，可得多听风声、多留个心眼啊。」】

**故事4（御前决斗：刀已断，神之眼成了空壳）**【摘要：旅途中结识的友人里，有一位与他感情尤其笃厚，两人一度结伴同行，因目的地不同而中途分别。「与友人本是萍水相逢，却能惺惺相惜，足见缘分颇深。虽然暂时分别，但或许不期之时又会重逢，万叶本是这么想的。」但时事破坏了他这份悠然——「将军大人亲颁眼狩令，誓要猎尽神之眼」，包括万叶在内身怀神之眼者无不惶惶，隐姓埋名、终日躲藏。就在这时他得知一个惊人的消息：有人毅然发起了「御前决斗」，而此人正是他的友人。「「御前决斗」中，战败者将受将军之罚。友人不惜冒此大险也要步上御前，既是为了与强者决胜，也是为了向世人昭示何为勇气。」但在如此关头发起决斗，一旦落败，生命恐怕会被将军大人的万丈雷明吞没。一向淡泊的万叶再难平静，提刀一路风行闯入天守阁，但一切为时已晚——「刀已断，神之眼成了空壳，抱憾逃离的万叶也遭到幕府通缉。」从此他无奈卷入一场又一场争斗，生活再也没有了从容。他不惧怕争斗，只是无止尽的争斗让他茫然；他不后悔那次无结果的营救，也不埋怨「壮烈成仁留他孤身一人的友人」，只是自问：「要贯彻道义，难道就必须如此与人相争吗？」】

**故事5（活人剑：道还没写完就被喊去搭手）**【摘要：如今的万叶以「南十字」船队为家，漂泊四海；偶尔麻烦仍会找上门，但有「南十字」一众人支持就不再棘手。坐在「死兆星」号高高的观测台上眺望碧海蓝天，他终于有心情回味那段动荡日子里的感受。武士们都愿自己一生热烈、以手中之刀博取无上名誉，「但其中总有人受欲念引诱，偏离「仁」与「义」的正道，挥刀留下无穷的仇恨」；「上天赋予众生血肉，神明护佑他们的生命，不是为了让人举刀相争的」。于是有了他的自白：「我所握的，不应当是杀人刀，而应是活人剑。终武士一生，须守一道，这便是我的「道」。」正想起诗兴留数句作座右铭，船上却传来不满的声音：「万叶啊，别窝在观测台上望天了，快下来搭把手啊！」——掌舵手海龙在叫他了，座右铭的事便下次再想。】

**神之眼的空壳**【摘要：那场大战中，「神之眼」竟然短暂亮起，万叶自己也十分意外。「千万般找寻，本想借别人的手再次点亮这枚「神之眼」，没想到它最终却因自己而亮起。如此情景，就像是从前的朋友仍在背后支持自己一般。」空壳不仅证明了这一点，还牵引他获得许多新的缘分——「旅途中受反抗军接济，被大姐头救下、收留，与传闻中的旅人相逢…」篇末自注：「活在世上固然有颠沛流离的时刻，却也有及时无比的邂逅。人生一途，如山路起伏，虽苦难万般，仍有触及云顶之时。」】

**神之眼（雨夜悟「空」「净」，翌日怀中新物）**【摘要：清晨山崖纱雾蒙蒙，小径上唯万叶一人；万籁俱寂，「既不见一羽之振，又不闻一虫之鸣」，涛涛海浪似乎也已眠去，仅剩风声幽响——「他知道，天要下雨了」。视线尽头有一缕炊烟、几间茅屋，他告诉茅屋主人大雨将至；主人起初将信将疑，但刚至晌午瓢泼大雨忽然簌簌而下，便衷心佩服起这个旅人，殷勤供上膳宿。夜里窗外潇然，他拥被卧听雨打秋叶，发起呆来：自枫原家家财散尽、少爷踏上旅程，他已走过数座岛屿；从稻妻的一座岛到另一座岛通常要渡海，孤身乘一叶小舟，若遇逆风或雷暴，路途愈发艰险。但这一路「以天地为屋宇，万灵为诗友，亦有无穷趣味」——「心至「空」处，天地万物皆为「空」；心中「净」澈，万物天地皆为「净」。手中有刀，心中有道，他便能一路歌咏前行，再多崎岖也无畏惧。」如此重整心情、带着满足沉沉睡去；「翌日，万叶被鸟鸣唤醒时，怀中多出了一枚莹亮的神之眼。」】

## 三、时间锚

- 枫原家败落（宅屋抵债、家仆散去）→ 浪游诸岛（雨夜悟道，获风之神之眼）→ 与友人结伴后分别 → **眼狩令颁布**（「将军大人亲颁眼狩令，誓要猎尽神之眼」）→ 友人发起御前决斗、败亡 → 万叶闯天守阁（为时已晚，刀断、神之眼成空壳）→ 遭幕府通缉 → 受反抗军接济 → 在离岛被北斗接上「死兆星」号 → 以船队为家 → 那场大战中空壳短暂复燃。
- 客串链：北斗与万叶「是朋友」在前，收留在后；「与传闻中的旅人相逢」即旅行者，构成稻妻主线同行的入口。
- 版本锚 2.x（稻妻）；语音中「风波平息后，「九条」家还能否延续曾经的昌盛」为眼狩令废止后的余波视角。

## 四、人物与关系变化

- **友人（名讳未提）**：萍水相逢而惺惺相惜 → 发起御前决斗壮烈成仁 → 其神之眼成为空壳、由万叶持有 → 空壳复燃时万叶感到「从前的朋友仍在背后支持自己」。全档最强的隐性在场者。
- **北斗**：旧友 → 恩人 → 「可以托付后背的战友」；关系由收留升级为互信。
- **九条裟罗**：「为虎作伥，我无法原谅」→「看来她也有自己坚持的信念」；同一人身上完成态度反转，并连带对九条家前景的疑问。
- **雷电将军**：切割式定性——不怨其对友人落下的一刀，只怨眼狩令本身。
- **五郎／反抗军／珊瑚宫心海**：通缉期的受助者与敬仰对象。
- **鹿野院平藏、宵宫、神里绫华**：侦探朋友、卸货之劳、无交集的「白鹭公主」。

## 五、隐喻与代指

- **「空」与「净」**：既是雨夜悟道的对句，又与「神之眼成了空壳」的「空」字形成双关——空壳之「空」是剥夺，心至「空」处之「空」是自由。
- **杀人刀／活人剑**：万叶对「道」的定义式对偶，直接回应故事4「要贯彻道义，难道就必须如此与人相争吗？」
- **风声**：全档的感知媒介——辨雨、辨妖（草庵）、辨危险；风暴时嘈杂则成其烦恼。
- **「飘摇风雨中，带刀归来赤脚行」**：诗句即身份铭，「带刀」与「赤脚」并置贵族残余与浪人现实。
- **刀**：「与故乡唯一的联系」——刀既是武器也是遗物，故「太久的停留会让刀变钝」实为对停滞的警惕。
- **「南十字」/「死兆星」号**：船名自带占星意味，观测台是他回望往事的空间装置。
- **枫叶**：「红时总多离别」，与其命之座「枫红座」互证。

## 六、悬案与待核

- 【待核】御前决斗中败给友人的对手：语音只说「能在御前决斗中战胜我的朋友」，主语为九条裟罗，但「战胜朋友」是裟罗胜了朋友还是朋友胜了谁，句法有歧义，需与稻妻主线他卷互证。
- 【推演】「刀已断，神之眼成了空壳」中的刀与神之眼归属：文本紧邻友人决斗，v1 判为友人之物由万叶持壳；但「抱憾逃离的万叶」亦可读作万叶自身之物。悬案保留。
- 【推演】「那场大战」的所指：神之眼的空壳篇未定名，需与稻妻主线「无想的一刀」／将军一心净土一战对读。
- 【推演】「风波平息后，「九条」家还能否延续曾经的昌盛」——九条家地位在眼狩令后的走向，可与九条裟罗档案互证。
- 【待核】枫原家「叱咤风云」的具体事迹与败落年代，库内无年表。
- 【待核】友人名讳（「壮烈成仁留他孤身一人的友人」）在角色档案体系中始终未记名。

## 七、与时间线的关联

- 个人史即眼狩令时期流亡武士史的缩影：神之眼持有 → 躲藏 → 友人决斗败亡 → 被通缉 → 渡海入璃月船队。
- 与北斗／南十字的璃月海上武装线、反抗军的海祇岛战线双向下嵌入，是稻妻—璃月两地联通的少数角色节点之一。
- 空壳复燃一事可作为「眼狩令收缴的神之眼能否复燃」这一命题的个案证据（明文，但仅限本人一枚）。
- 【推演】「与传闻中的旅人相逢」将万叶的流亡线并入旅行者稻妻主线，其「重返稻妻的勇气」正对应主线终局的眼狩令废止。
