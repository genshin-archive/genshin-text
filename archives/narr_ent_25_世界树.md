# 实体档案：世界树

> 按 STANDARD v1.0 重建。底稿：archives_v1/ent_25_世界树.md（实体档案批次F）；引文均逐字摘录自 v1 底稿所标出处。类型：器灵（原初之树／记录装置；先于天理存在的存续之物）。

## 一、叙事流摘要

【旁白】别称：世界树（全库通称）；「原初的提瓦特之树」（arch_1611 talk 603610，时之执政语）；「记录一切信息的存续装置」（arch_1611 talk 603407，纳西妲语）；「贪婪之树」（arch_1611 talk 603412，纳西妲语，异变期称谓）；阿如（继任者，被称「新的世界树」，arch_1611 talk 603807）。

【旁白】状态：明文存在。现状：被火神之心焚烧七日，「世界树仅剩下地表以下的部分」，记录职责由阿如接任（arch_1611）。

【阿佩普（arch_1609 talk 303510）】先于天理：「这棵树并非天理栽种的，在天理到来提瓦特之前，世界树就已经存在了。」；改造者与所有者：「是天理夺走了世界树，加以改造，使其为人类所用。」

【纳西妲（arch_1611 talk 603502）】「世界树先于天理存在，早在纳塔龙族鼎盛的时期，它就存在。」；「世界树通常基于记录产生影响。」；并说明天理定下的规则「当世界树陷入严重危机时，会确保留出一部分力量将须弥隔绝。」

【纳西妲（arch_1611 talk 603407）】「「天理」降临后，使光界力化分为元素力，将世界树改造为记录一切信息的存续装置。」

【纳西妲（arch_1305 talk 302818）】与大慈树王的关系：「作为大慈树王，我是世界树的化身，而你则是世界树上折下的最纯净的枝杈」；并记五百年前「当初除我以外的七神都被召集前往名为坎瑞亚的国度」。

【纳西妲（arch_1305 talk 302813）】千年前的禁忌知识污染：「依靠赤王的自我牺牲与大慈树王的透支力量才成功驱逐。」

【旁白】现代：3.x 大慈树王被抹除（arch_1305）、散兵自删改写历史（arch_1307）；7.x 须弥灾变（arch_1609）、多托雷入侵、焚树七日、阿如接任（arch_1611）。1609 灾变期「死者的灵魂将无法被收容，生者的认知也会遭到扭曲」（arch_1609 talk 303410）；1611 多托雷借死者灵魂回归地脉之通道入侵世界树内部，纳西妲行使最高权限，以火神之心焚树七日。灾后纳西妲称「提瓦特最重要的那些信息基本都被保存了下来」（未言无遗失）；火神之心在世界树残骸中下落不明——「就连被化为灰烬的痕迹都没有」。

【旁白】同源物：散兵核心「由纯白的树木制成，是世界树的一小部分」（arch_1608）；银白古树为「世界树延伸出来的枝杈。曾和世界树相连」（arch_1605）。旅行者为不被记录者——世界树内没有关于他的记录，故世界树无法阻挡他（arch_1611 talk 603502）。

## 四、人物与关系变化

- 世界树—天理：改造者与所有者（阿佩普语）。

- 世界树—纳西妲与阿如：纳西妲为守护者，接入世界树充当信息流转中枢而濒危、后行使毁灭世界树的最高权限；阿如为其继任者，与纳西妲的存在根基关联。
- 世界树—多托雷：入侵者——以「最后的数据备份放入了地脉」的方式渗入世界树。

- 世界树—散兵（流浪者）与银白古树：均与世界树同源。
