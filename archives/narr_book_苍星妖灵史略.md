# 《苍星妖灵史略》（书籍·现存第一卷）

> 按 STANDARD v1.0 重建。底稿：archives_v1/book_苍星妖灵史略.md（v1 简表）；语料：genshin_text.db entries（entry_id=Book1197，category=书籍信件）；引文已逐字回查。

## 一、叙事流摘要

【摘要：至冬妖精（妖灵）王朝编年史，所存部分为第一卷，含正文与 [127]-[140] 号脚注，纪年从第四百二十八纪跳至第七百九十九纪。记录莫诺马赫白沙皇统一妖灵与安娜丝塔夏女皇建制「愚人众」两大转折，是至冬古代史与近代政制的核心史料。】

### 第一段（四百二十八纪）
第四百二十八纪第三年，莫诺马赫·雪奈茨尼伊皇帝在冻土上修筑帝都基捷已七十六年；皇帝使者质问风仙部族「你们向谁缴纳贡物」，风仙答「我们向穆斯季斯莱沃王缴纳贡物」，使者以「贡物是不仁爱的」劝止，风仙遂不纳贡。第六年，穆斯季斯莱沃王谴责苍星王廷破坏和平协议，要求皇帝向兽怪联盟缴纳十年贡物（每年六百谷仓粮食、三十谷仓黄金，及搬动它们的奴隶），「这是风仙向他们缴纳贡物的三十倍」；皇帝拒绝，宣言「我们的战友是刀剑与仁爱」「不是品尝胜利的蜜酒，就是光荣地牺牲」。第七年，穆斯季斯莱沃王率穆斯季斯莱沃洛、尼约默罗德（牛形）、达洛格莱德（水妖）、切纳雷卡（狼形）诸氏族及仆从攻打基捷，三战（基捷山麓、冰湖、平原）：皇帝以长枪贯穿杀死穆斯季斯莱沃王；苏古基列特大公（「森之牡牛」）中伏被杀，沃佳瑙大公（「无地王」）被诱出冰湖而亡，唯「灰狼」瑟里维克幸免。皇帝自称「苍星的继承者，是全体妖灵的庇护主」，余下妖灵氏族来觐见，「从此自称为白沙皇」。

**脚注补密：** [127] 基捷是「全至冬的第一座城市」，建于第四百一十七纪第四年，至皇帝「赦恕人类为臣民，并迁都至冬堡」止为权力中心。[128] 穆斯季斯莱沃即《沃尔霍编年史》的「饮血者」，亦被称作「戈里尼什青」（山之子）。[130] 注者指出战争真正原因是穆斯季斯莱沃王「惧怕苍星王廷自上一场战争以来的崛起」。[135] 末战中穆斯季斯莱沃王「尝试利用了阴影世界的力量」未果；侧翼施佩金军团「很蹊跷地为冰雾所惑」延误战机。[136] 瑟里维克战前即与苍星财政大臣波里菲尔有私往，学者疑其军团失败「或许并非偶然」。[139] 皇帝的「长枪贯穿」实为「将长枪作为箭矢，以常识无法想象的力量引弓发射」。[140]「神圣的血脉」被注者判为正统性说辞。

### 第二段（七百九十九纪）
第一年安娜丝塔夏·费奥多罗夫娜加冕为全至冬女皇，许多妖精王公未往觐见（「因为莫诺马赫皇帝已死，达洛格莱德氏族与至冬堡断绝了往来」）。第二年贝洛沃迪港人类宣布自治。第三年女皇镇压自治军，沿途强占卓沃戈列、伏尔霍凡、切纳雷卡领地，「攫夺原本统治这些领地的王公头衔，改由非世袭官吏接管」；她「没有集结冬契军，而是组建起一支被称作『愚人众』的队伍」；谴责女皇谋反的卓沃戈列大公战死；三月十日安抚贝洛沃迪港自治军成功，三月二十三日要求觐见的王公交出所有权力，「许多王公在答复女皇的要求前就去世了」。「这时候，安娜丝塔夏女皇掌管北方的大权。」第四年建城塞格鲁波夫，「意思是愚人之城」。第六年设皇都评议会，初任议长为人类约安娜·伊万诺夫娜。第七年《帝国秩序改良诏书》颁布，许多妖精王公「主动放弃贵族的名誉头衔，离开至冬」。

## 三、时间锚

- 文内纪年体系：「第 X 百 Y 十 Z 纪的第 N 年」——至冬妖灵纪年。可提取锚点：
  1. 第四百一十七纪第四年：基捷建城。
  2. 第四百二十八纪第三年：建城第 76 年（与上条自洽：417-4 → 428-3 恰为 76 年整【推演：由两条数据推算核验一致】）。
  3. 第四百二十八纪第七年：三战役与白沙皇称号确立。
  4. 第七百九十九纪第一年至第七年：安娜丝塔夏加冕至《帝国秩序改良诏书》，与上一段相隔约 371 纪【推演：数值为算术结果，两段之间的史事缺载】。
- 叙述时态：编年史体，脚注为后世注家口吻（「即使在后世看来」），成书远晚于所记事件。
- 时间异常：纪年跨度巨大（四百至七百九十九纪）而史事叙述连续，纪与年的换算关系不明【待核】；「许多王公在答复女皇的要求前就去世了」的集体死亡原因未明，是重大异常记载。

## 四、人物与关系变化

- 莫诺马赫·雪奈茨尼伊皇帝：苍星王廷之主，统一妖灵诸氏族，「从此自称为白沙皇」。
- 穆斯季斯莱沃王：兽怪大君王，「饮血者」「戈里尼什青（山之子）」，战败身死。
- 瑟里维克（灰狼）：切纳雷卡统治者，疑似通敌，战后受长剑拍肩之仪。
- 苏古基列特（森之牡牛）、沃佳瑙（无地王）：战死的大公。
- 波里菲尔：苍星王廷财政大臣，与瑟里维克有私往。
- 阿尔维斯：矮灵们的大公，用计诱沃佳瑙离湖。
- 菲利波夫：「最擅长变化」的妖精，效忠皇帝，窃取敌方战略。
- 安娜丝塔夏·费奥多罗夫娜：全至冬女皇，建制愚人众、废王公、设评议会。
- 约安娜·伊万诺夫娜：皇都评议会初任议长（人类）。
- 卓沃戈列大公：反女皇而死。
- 「苍星」「妖灵/妖精/兽怪/矮灵」：本卷的至冬族群谱系——妖灵为总属，下分兽怪（牛、狼、水裔诸形）与妖精等【推演：属种关系由行文归纳】。

## 五、隐喻与代指

- 「愚人众」：女皇新建的非氏族武力组织——本书是「愚人众」之名的最早建制出处；格鲁波夫「愚人之城」与之配套。
- 「苍星」：王廷/皇权的天象代称；「白沙皇」：以色冠名的至冬统治权标记。
- 「仁爱」的语义考：脚注 [129] 释为「有益的、可爱的」，使者之言可读作「隐晦的威胁」——政治辞令的双面性样本。
- 「阴影世界的力量」：穆斯季斯莱沃王绝望中的手段，「对皇帝日后的决策产生了一定影响」，所指未明【待核】。
- 「冰雾所惑」：施佩金军团反常失误，注者以「天气突变的原因依然不明」留白，与瑟里维克通敌说构成双解。
- 「许多王公在答复女皇的要求前就去世了」：官方叙事下的集体死亡，注家不置一词——清洗的曲笔【推演】。
- 长枪作箭（[139]）：把不可能的阵战记述转写为超人武力，神话化书写的自我修复机制。

## 六、悬案与待核（推演只在此节）

- 【待核】四百二十八纪与七百九十九纪之间约 371 纪的空白期内妖灵王庭史。
- 【待核】莫诺马赫之死与达洛格莱德断交的因果。
- 【待核】纪年与提瓦特通行纪年的换算。
- 【推演】「阴影世界的力量」所指，及其对皇帝决策的影响。
- 【待核】本卷是否即「第一卷」全貌，后续卷是否存在。
- 【推演】「许多王公在答复女皇的要求前就去世了」是否为女皇清洗的曲笔，注家不置一词。

## 七、与时间线的关联

- 可锚定节点：
  1. 第四百一十七纪第四年：基捷建城，「全至冬的第一座城市」。
  2. 第四百二十八纪第七年：莫诺马赫三战灭穆斯季斯莱沃，称白沙皇——至冬统一节点；同期「赦恕人类为臣民，并迁都至冬堡」。
  3. 第七百九十九纪第三年：「愚人众」组建——至冬现行政制（愚人众、非世袭官吏、皇都评议会）的起源点。
  4. 第七百九十九纪第七年：《帝国秩序改良诏书》，妖精王公体系终结，「女皇掌管北方的大权」。
- 与《至冬国通史》互文：本书述信史层（三战灭穆斯季斯莱沃、称白沙皇、愚人众建制），《至冬国通史》述传说层与莫诺马赫远行、远征，两书拼接为至冬古史骨架。
