- 「七大高塔之城」「二十九代伊之城」「僭称哈冈」「苍暮细雨」四个新名词一律入库，不得以意译替代。
- Relic15027_4 的三段「言及…」排比、密约的**双重资格条件**（未尝被磨砺成为铁石／未尝被虚假的蜃境腐蚀）、以及「如先知那般统治羊群般迷惘的民众」的统治喻式，皆是设定级明文。
- 镇灵两句祝辞（百世祝福／代价为复仇的利刃、鲜红的酒浆；狂爱伴随贪婪索求／终结于自以为公正的残酷报复）必须逐字全录，两句为预言体。
- 「睡莲中诞生的利露帕尔」为利露帕尔出身的唯一本组明文；「赤砂之主的代行」为奥尔玛兹名分的最终定位。
- 末尾**听讲者层**不可漏：西福斯携师父（即盲眼老者）讲述的往事前往蓝宝石之城；「明日又将随着无穷的时光之风重演」是文本自陈的历史循环论题眼。
- Relic15028_5 的四层结构须按序保留：陵园建造（源力＝晶石、助力＝镇灵）→ 千百年后部族传说（两条「游牧民说」）→ 部族政治（三族主母自称「花神的女儿」；信仰为基准、血脉为纽带、幻想中的帕蒂莎兰园圃）→ 三位伙伴翻案＋收束。
- 「永恒绿洲」在本条中被文本自身命名为**「永恒谎言」**，并以「凝滞的绿洲正存在于部族的空想中」收束——本组的结论性判语，绝不可写成正面设定。

## 三、时间锚
- 「在那场胜利之后的十个年头，是名为「苍暮细雨」的好时代」——撒勒布·道莱王朝的十年盛世锚，以「那场胜利」为原点｜Book477｜明文。
- 「是岁，二十九代伊之城…远来纳贡」——「是岁」把纳贡事件系于盛世纪年之内｜Book477｜明文。
- 「僭称哈冈的…年头结束」——僭位时代的终点，与古达尔兹称王为同一节点｜Book477｜明文。
- 「赤砂之王在伴侣逝去后，以镇灵为使前往与凡人立密约」——密约的发动时刻系于「伴侣逝去」之后｜Relic15027_4｜明文（传说时态）。
- 「彼时年轻的牧羊人奥尔玛兹」——牧人期锚，位于密约立约之后｜Relic15027_4｜明文。
- 「我将为你留下百世的祝福…」「终结于自以为公正的残酷报复」——预言式时间锚（指向尚未发生的结局）｜Relic15027_4｜预言。
- 「居尔城如人造之花在山壁盛开，成为凡人国度的首都」→「华丽绽放之后所命定结成的，正是死亡那暴烈的苦果」——建城与暴亡的两端锚，中间无纪年｜Relic15027_4｜明文＋预言。
- 「携着师父娓娓讲述的古老往事，西福斯踏上前往蓝宝石之城的道路」——**听讲者层**的当代锚：老者的讲述发生在西福斯上路之前｜Relic15027_4｜明文。
- 「在只有镇灵才能为之叹息的过去，赤砂之主曾为他的挚爱修建陵园」——陵园建造为最古层｜Relic15028_5｜明文（回忆时态）。
- 「千百年后，沙漠中流浪的诸部族之间流传着「永恒绿洲」的传说」——明确的千百年跨度锚（陵园 → 部族传说）｜Relic15028_5｜明文。
- 「那时三位伙伴的闲聊，随风飘荡在千百年后的沙漠之上」——把「那时」的言语与「千百年后」的接收并置，构成跨千年的回声结构｜Relic15028_5｜矛盾对（倒流式并置）。
- 「神主所遗下的预言」——预言锚位于部族失神之前，且被文本判为已应验（「凡人仍顽强地生存下来」）｜Relic15028_5｜预言＋明文。
- 时间异常：Book477 上半／下半为不同笔迹（「不知何人所留」），同碑异时；石碑上半的「三日之战」与 Relic15027_4 的「牧人加冕」分属两套王统叙事，碑不记奥尔玛兹，讲古不记古达尔兹。

## 四、人物与关系变化
- 赤砂之王／赤砂之主：伴侣逝去者 → 以镇灵为使立密约的「伟大主人」→ 为挚爱修建陵园者 → 其「代行」（奥尔玛兹）受封藩王。全组中他始终不出场、只以「传说」「游牧民说」层在场。
- 利露帕尔：睡莲中诞生者 → 与奥尔玛兹相爱 → 留下百世祝福与警告者 → 其「狂爱—贪婪索求—残酷报复」被讲成居尔城毁灭的机制。与 narr_1609（镇灵之母、居尔城三代复仇、身躯融入地下压制漆黑灾劫）、narr_1611（爱 娜布·玛莉卡塔、心愿再见一面）互证。
- 奥尔玛兹：年轻的牧羊人 → 流浪氏族首领 → 战胜割据群主 → 一方藩王 → 赤砂之主的代行 → 「卑贱出身的王」；对警告「并未放在心中」。
- 古达尔兹：图莱杜拉之主 → 战僭称哈冈之逆贼（三日不克，因幻景而胜）→ 迁入居尔城王廷 → 号令七大高塔之城 → 改名号「撒勒布·道莱王」→ 受阿赫玛尔显圣助称王 → 大征民役立像 → 纳二十九代伊之城之贡而不究其掠。
- 阿赫玛尔：显圣降幻景者、被广立像者。本档只按碑文立论；其与「赤砂之主／赤王」是否同一实体，另有文本判为身后尊号（见悬案）。
- 菲莉吉丝：最后的镇灵母亲、永恒绿洲门扉的守护者、对一切凡人施祝福者（与 narr_frag3_帕维兹拉万朝神官密报 的「赤王亲委守护永恒绿洲的大镇灵」互证）。
- 花神：赤砂之主的挚爱（陵园为谁而建）→ 永远沉睡、统治永恒绿洲者 → 三族主母所自称之「女儿」的名分来源。
- 塔尼特／乌萨／欣缇：失神后仍「彼此分裂、挣扎求生」的三部族，以信仰与血脉自我团结——本组为其政权合法性的神话基建层。
- 盲眼老者 → 西福斯：师承链，教训的代际传递；西福斯是讲述唯一在场的听众。
- 三位伙伴：无名，向「我的王」发问者，承担对「永恒」的翻案。

## 五、隐喻与代指
- 「人造之花／瞬灭」：居尔城与花神的双关——花之绚烂与暴亡同体；亦讽喻一切「永恒绿洲」式乌托邦（v1 判，本版保留为文本自身明言：「『永恒』的从来不是什么乐园」）。
- 「复仇的利刃、鲜红的酒浆」：以宴饮意象预告血案。**跨文本联动·已核**（两处库内明文，因果联结属推演）：narr_book_希鲁伊与希琳的故事（Book428）记「将蝎毒滴入麝香的蜜糖，呈予藩王奥尔玛兹与他的三百子嗣」，奥尔玛兹「死于大宴之夜」——毒酒与蜜糖正落回「鲜红的酒浆」这一预言的字面。两档独立明文，但无文本自陈二者同一事件，故联结本身标【推演】（见悬案节）。
- 「睡莲中诞生」：利露帕尔的出身意象，与花神（花）系谱相邻，本组未明言其关联。
- 「如先知那般统治羊群般迷惘的民众」：牧人—羊群—先知的同构，奥尔玛兹由牧羊人成藩王的路径在其统治喻式中已被预告。
- 「未尝被磨砺成为铁石者／未尝被虚假的蜃境腐蚀者」：密约的双重否决条件；与「幻景骤起助古达尔兹」形成对照——碑文中的王靠幻景得国，讲古中的王以不受蜃境腐蚀为资格（张力为文本自身，非本版推演）。
- 「苍暮细雨」：盛世名以天色与雨为名，与「泪尽的盐漠」「流动的沙丘」共同构成沙漠水文意象群（排水／泉流／细雨／泪）。
- 「时计／晶砂凝固一团」：以沙漏写「停滞即无意义」，与 narr_frag_千岩时计与日御传说 的时计意象同族（跨条联动·未验证，只登记）。
- 「花一般盛放、毁灭、又在花季重生」：对「永恒」的替代方案——循环而非凝滞；与「无根的部族随沙丘继续生死的循环」同句收束。
- 「蓝宝石之城」「风在此哀歌已久」「风亦无法追及的大地边缘」：三处地理修饰语，为图莱杜拉与居尔城的名物别名（蓝宝石之城与 narr_frag_沙漠王国编年 Weapon14512「蓝宝石的城邦如泪滴浮现」**跨文本联动·已核**）。
- 「永恒谎言」：文本自我拆解设定名称，属须弥部族叙事中最锋利的元叙述句。
- 术语警戒：本组「花神」「赤砂之主」「阿赫玛尔」「神主」「伟大主人」为不同文本层的指称，未经明文不得合并（STANDARD 第五节）。

## 六、悬案与待核（推演只在此节）
- 【待核】「盘踞在居尔的…」是谁、「其兄」为谁：碑文残断，兄弟追捕关系无主语可补。
- 【待核】「僭称哈冈」的「哈冈」为何种名号／职位（僭称的对象未载）；「七大高塔之城」「二十九代伊之城」的成员与地理位置全部未载。
- 【待核】「阿赫玛尔」与「赤砂之王／赤砂之主／赤王」是否同一实体：本组碑文作神格供奉对象（「显圣」「广立其像」），而 narr_book_牧童与魔瓶的故事（Book426 注4）明言「『阿赫玛尔』并非此位君王在世时之称谓」——两说冲突，本版不合并。
- 【推演】古达尔兹（撒勒布·道莱）与奥尔玛兹（赤砂之主的代行）两套王统的先后：本档第七节按 v1 判「奥尔玛兹建居尔城 → 赤王殒 → 古达尔兹借幻景复国」，属推演（碑文自身无绝对年代，讲古体亦不记古达尔兹）。
