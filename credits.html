鸣谢与数据来源

本页说明本站数据的来源、验证与许可。一切以游戏内文本为唯一事实源，详见 数据可用性声明。

一、数据源 · Dimbreath / AnimeGameData2

本站全部游戏文本（任务对话、书籍报刊、武器故事、过场字幕等，入库 123 万条）来自开源数据镜像项目 Dimbreath/AnimeGameData2（v7.1.0，2026-09-21）。

由衷感谢 Dimbreath 长期以个人时间维护并持续更新这些（几乎）完整的游戏数据导出——没有这个项目，本站无从谈起。若您也使用该数据镜像：

  • 数据问题反馈（ExcelBinOutput / BinOutput / TextMap 数值不匹配或错误）：按原仓库 README 指定渠道，通过 Twitter 私信联系 Dimbreath；
  • 支持作者：patreon.com/Dimbreath——作者自述为个人小费罐（非强制），作为对业余时间持续维护的感谢。

本页即原仓库 README 所请求的「鸣谢署名」落位处；数据获取与建库复现步骤见 SOURCES.md。

二、外部交叉验证（仅辅助，不作断言依据）

以下来源仅用于覆盖率校验与分类校正，与游戏文本冲突时一律以游戏文本为准：

四、技术栈

全文检索基于 SQLite FTS5（trigram）全文索引；本地版服务基于 Python FastAPI；展示站为纯静态构建（GitHub Pages）。 精读档案生成与审计动用多引擎管线，并经三模型交叉审计（GLM / Qwen3.8 / DeepSeek）+ 作者人工校验，详情见仓库 CHANGELOG。

五、反馈与勘误

发现任何错误或遗漏，欢迎走 勘误 Issue 模板 （请附任务名/书名 + 原文片段，有出处的反馈优先核实），或到 Discussions 参与考据讨论。 处理流程见 CONTRIBUTING.md。
